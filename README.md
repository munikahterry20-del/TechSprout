# TechSprout exact-style rebuild

This version follows the structure/content of the live TechSprout /tech/ page and replaces its generic visual placeholders with the image assets from the first TechSprout website.

Upload the entire folder to GitHub Pages. Keep `index.html` in the repository root and keep the `assets` folder beside it.

Interactive features included:
- responsive navigation
- dark mode saved in localStorage
- Schools & NGOs / Parents & Students tabs
- project category filters
- audience selector
- inquiry form with localStorage persistence
- responsive mobile layout
- working anchor navigation
